## 2026-10-23 V6 更新核对

- 页面范围：V6 已移除整表关联按钮、关联清单弹窗、数量预加载和从清单进入的最短路径交互；Java 前端已同步。关联清单与最短路径后端接口仅在存在外部调用方时作为兼容能力保留，不作为当前页面迁移验收项。
- 值血缘：V6 明确了目标投影、别名修正、父路径与兄弟路径中间值链、多步中间值链，以及 SQL 无法确认目标时保留 JSON 显式来源并标记待核查。Java 当前实现已同步这些规则；SQL 证据不足时保守保留关系并输出核查诊断。
- 业务标签：V6 的 2026-10-23 核查说明确认，标签筛选只约束当前字段的直接入口；更深上游展示所选来源的完整普通字段血缘，下游展示普通字段引用，均不代表整条链路已被同一业务标签确认。候选/部分解析仍标记为候选。Java 当前按此边界实现，业务条件跨层传播不属于本次同步功能。
- 数据核查边界：缺少 sources、标签定义缺失或多义、SQL 别名无法绑定属于源定义证据不足。Java 不根据说明文本虚构来源，也不把候选链路提升为已确认结果。
- GaussDB 稳定性：V6 在读取载荷遇到可重试连接错误时会关闭旧读连接并重连一次。Java 使用 JDBC 连接池，并已启用借用前校验；文档恢复读取对 SQLState 08、57P01/57P02/57P03 及可恢复/瞬时连接异常最多重试一次，普通 SQL 错误不重试。

本轮新增回归及打包验证覆盖：

- 别名笔误、父路径、多步兄弟路径的修正信息进入关系证据；多步返回 `intermediate_fields` 和 `via_paths`。
- UPDATE 只消费目标赋值中的中间字段；其他赋值、WHERE 条件、未使用投影和其他路径分组不成为目标值链。
- SQL 表达式采用 AST 相等比较，容许最外层括号和不影响语义的格式差异，保留字符串常量的大小写和内部空格；同时核对带引号字段的值链。
- 所有路径均无法确认目标时保留 JSON 来源并标记 `declared_source_fallback`；已有确认分支时继续过滤辅助分支。
- 在临时 SQLite 库导入合成样例，相同内容重导跳过；重启后图和修正信息保持一致；修复 SQL 后按同身份更新，待核查诊断清零。
- 业务标签只标记直接分支，较深上游的 `business_match_count=0` 且 `business_propagated=false`。
- Edge 无界面浏览器验证选表、字段切换、15 层追踪、业务选择、节点展开和修正说明展示；页面无 JavaScript 错误，无关联表或最短路径接口请求。静态资源版本号已更新。

这些验证使用合成样例和本地 SQLite，不代表已完成真实 GaussDB 或生产全库一致性验收。GaussDB 的连接校验、一次读取重试及不重试普通 SQL 错误由故障注入测试覆盖，上线仍需真实环境演练。

## 有意保留的差异

2026-10-23 补充：[SQL 解析兜底与核查](SQL_FALLBACK_STRATEGY.md)。无法判定时保留显式关系，证据返回 `sql_analysis`，质量报告提供 `SQL_ANALYSIS_FALLBACK`，修复后的同身份增量更新会重新计算状态。

2026-10-23 SQL 兜底阶段的历史验收为 46 个测试全部通过；本轮最新结果以上方 58 个测试和覆盖率为准。当时已运行打包 JAR 验证：坏 SQL 所在 JSON 正常导入、两条显式来源关系保留、共享逻辑路径只产生一条核查诊断；修复 SQL 后增量覆盖成功，核查诊断清零。

- Python V6 数据库不能原地作为 Java 数据库使用；首次迁移使用空 Java 库并全量导入当前有效 JSON。
- SQL 值血缘判定由 Druid 实现。无法可靠解析的语句采用保守策略，保留显式来源关系，不会因为解析失败删除已有血缘。
- Java 运行包不包含 Python、`sqlglot`、Python 服务调用或端到端报告代码。
